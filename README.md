# sltnlabs.github.io

The SLTN Labs website: studio home page and app privacy policies.

- `/` studio home
- `/rookie-star/` Rookie Star product page
- `/rookie-track/privacy.html` Rookie Star privacy policy (path kept from the old name)

Served by GitHub Pages. To use sltnlabs.com later, add a `CNAME` file containing `sltnlabs.com` and point the domain DNS at GitHub Pages.
